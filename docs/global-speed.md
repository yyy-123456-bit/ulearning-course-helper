# Global Speed 安装与倍速使用（Edge 扩展商店）

> 本文是**可选的第三方工具说明**，不属于本项目功能。默认不建议在优学院上使用高倍速，理由见 §1 与 §7。

---

## 1. 先看这一节：它和本项目脚本会冲突

本项目脚本每 2 秒会检查一次视频的 `playbackRate`，发现与面板设定值不一致就**拉回设定值**（`v1.0.0` 中为 1.0x）。
而 Global Speed 的工作方式正是直接改写同一个 `playbackRate`。两者同时开启的结果是：

- 你把 Global Speed 调到 2x → 最多 2 秒后被脚本改回 1x → 看起来"倍速不生效"；
- 更常见的是两者反复覆盖，表现为**视频速度忽快忽慢**（注意：脚本面板里的下拉框显示的是设定值，不会跟着跳）。

**三种共存方案（按推荐度排序）**

| 方案 | 做法 | 代价 |
|---|---|---|
| A. 只用脚本倍速（推荐） | 不装 Global Speed，用面板里的 1.25x / 1.5x / 2.0x | 最高 2x，够用且不额外增加指纹 |
| B. 两边设成同一个值 | 脚本面板选 1.5x，Global Speed 也设 1.5x | 需要每次手动对齐，改一边要改另一边 |
| C. 暂停脚本后用扩展 | 面板点「⏸ 暂停」，再用 Global Speed 控速 | 自动翻页、自动作答同时停止 |

> 结论：**要么用脚本的倍速，要么用扩展，不要两边各调各的。**

## 3. 启用与授权（最容易卡住的一步）

装完不显示、点了没反应，90% 是这一步没做：

1. **固定到工具栏**：点地址栏右侧的拼图图标 🧩 → 找到 Global Speed → 点「显示在工具栏」/ 图钉；
2. **授予站点权限**：Edge 的站点访问默认通常是「仅在单击时允许」。点扩展图标 → 「网站访问权限」→ 选
   - 「在 ulearning.cn 上允许」（更克制），或
   - 「在所有站点上使用」（更省事，但权限更大）；
3. **刷新页面**：权限变更后必须刷新，扩展才会注入到已打开的标签页；
4. **确认已激活**：地址栏右侧出现播放器小图标 / 扩展图标上出现角标，说明当前页已被接管。

**iframe 场景**：优学院部分课件把播放器放在 iframe 里。Global Speed 默认不跨框架注入，
需在扩展选项里打开「在 iframe 中启用 / Enable in iframes」，否则表现为"面板能开、视频不动"。

## 4. 常用倍速设置

**面板直接选**：点扩展图标 → 拖动或点预设档（0.25 / 0.5 / 0.75 / 0.9 / 1 / 1.1 / 1.25 / 1.5 / 1.75 / 2 / 2.5 … 16）。

**精确输入**：面板上的数字框可直接键入，例如 `1.3`、`1.75`（步进精度以实际版本为准）。

**按站点记住（URL 规则）**：选项 → 「URL 规则 / URL Rules」→ 为 `*.ulearning.cn` 单独设一个固定倍速。
好处是每次打开自动套用，不用重复调；坏处是设错后"每个视频都变快"，容易忘了改回来。

**快捷键（作者默认值，以你安装版本的选项页为准，均可自定义）**

| 操作 | 默认键 |
|---|---|
| 加速 / 减速 | `D` / `A` |
| 重置为 1x | `S` |
| 快进 / 后退 | `X` / `Z` |
| 逐帧前进 / 后退 | `Shift+X` / `Shift+Z` |
| 临时加速（按住） | 可在选项里绑定 |

> 快捷键是**全局监听**的。在填空题里打字时按到 `A`/`D`/`S` 会改倍速甚至重置——
> 建议改成 `Alt+` 组合键，或在答题时先点「⏸ 暂停」扩展。

**幽灵模式（Ghost Mode）**：用于绕过网页自身对倍速的限制。它同时也会绕过平台的"正常播放"假设，
**在优学院上不建议开启**，理由见 §7。

## 5. 适用场景

| 场景 | 是否适合 | 说明 |
|---|---|---|
| 纯录播、无进度校验的公开课 | ✅ | 1.5x–2x 提升效率 |
| 复习二刷已看过的章节 | ✅ | 但平台若按"有效观看时长"计分，仍需挂满 |
| 听力/语言材料精听 | ✅ | 0.75x 慢放，比反复拖进度条好用 |
| 优学院等有学习时长校验的平台 | ⚠️ | 只建议 1.25x–1.5x，且不要长时间挂机 |
| 考试 / 限时测验 | ❌ | 与倍速无关，反而增加异常行为特征 |
| 直播课 | ❌ | 直播流不支持倍速 |
| DRM 保护的内容 | ❌ | 播放器拒绝改写速率 |

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 装了但面板打不开 | 未固定到工具栏 | 拼图图标 🧩 → 固定 |
| 面板能开，视频不动 | 当前站点未授权 | 扩展图标 → 网站访问权限 → 允许 → 刷新 |
| 设了倍速没反应 | 被本项目脚本拉回设定值 | 见 §1，统一成同一个值 |
| 只能加速、不能拖动进度 | 平台锁了进度条 / 校验有效时长 | 属平台限制，扩展无法绕过（除非开幽灵模式，见 §7） |
| 面板显示倍速但声音变调 | 未开启"保持音调" | 选项 → 音调 / Pitch → 勾选保持原调 |
| 打字时倍速乱跳 | 快捷键全局监听 | 改快捷键或暂停扩展 |
| 换页面后倍速丢失 | 未配置 URL 规则 / 该页是新标签 | 配置 URL 规则；或每个标签单独设定 |
| 校园网环境装不上 | 商店请求被拦截 | 换网络（手机热点）再装 |

## 7. 注意事项与风险

1. **平台侧能测算有效学习时长**。优学院这类平台通常记录"播放时长 / 进度"，高倍速会让单位时间内的进度增长异常，
   已有用户反馈过**学习记录清空或回退**；本项目脚本的风控提示里也写了这一点。
2. **建议上限 1.25x–1.5x**，且不要整晚挂机、不要多标签同时刷。16x 只适合无校验的公开视频。
3. **幽灵模式 = 对抗性规避**。它绕过的是平台主动设置的倍速限制，性质比"自己调快一点"更重；
   一旦被判定异常，申诉空间更小。本文不推荐在优学院开启。
4. **权限范围**。选「在所有站点上使用」意味着扩展可读取你所有网页；虽然该项目声明不收集数据、开源可查，
   仍建议按最小权限原则只授权 `ulearning.cn`。
5. **它不是脚本的替代品**。Global Speed 只管倍速，不会翻页、不会答题、不会识别题型。
6. **卸载**：`edge://extensions` → 找到 Global Speed → 「删除」。卸载后若发现视频仍是 2x，
   检查是否残留 URL 规则缓存，或页面未刷新。
