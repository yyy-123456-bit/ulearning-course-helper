# 优学院课件助手 · 使用说明

一个只跑在优学院（`ulearning.cn` / `umooc.com.cn`）的轻量用户脚本：
**自动播放视频 → 播完自动翻页 → 用本地题库自动填练习题**。
不加速（默认 1x）、不模拟鼠标键盘、不自动交卷。

- 文件：`ulearning-course-helper.user.js`
- 版本：v1.0.0（2026-11-18）
- 运行环境：Tampermonkey（篡改猴）/ ScriptCat（脚本猫）/ Violentmonkey
- 相关文档：[排查手册](troubleshooting.md) · [浏览器级倍速扩展说明](global-speed.md)

---

## 一、安装

**篡改猴（Tampermonkey）**
1. 点浏览器扩展图标 → 管理面板 → 「+」新建脚本；
2. 删掉模板内容，把 `ulearning-course-helper.user.js` 全文粘贴进去；
3. `Ctrl+S` 保存，确认脚本列表里开关是开启状态。

**脚本猫（ScriptCat）**
同上，或直接把 `.user.js` 文件拖进浏览器窗口，会自动弹出安装页。

> 安装后打开优学院任意课程页，右上角出现蓝色「优学院助手」面板即成功。
> 如果没出现：确认地址里带 `learnCourse` / `homework` / `quiz`，或点扩展菜单里的「显示/隐藏优学院助手」。

---

## 二、使用流程（贴合优学院的操作顺序）

1. 登录优学院 → 进入课程 → 点「课件」标签，进入学习页；
2. 面板自动出现，点 **▶ 开始**（默认已在运行）；
3. 视频自动静音播放；播完自动点「下一页 / 下一节」；
4. 遇到练习题：脚本按题库自动勾选答案；
5. 全部填完且无未匹配题、且你打开了「自动提交」时，才会点提交；否则留给你自己检查。

**推荐配置**（面板里勾选）

| 选项 | 建议 | 说明 |
|---|---|---|
| 静音播放 | 开 | 不打扰，也不影响进度统计 |
| 暂停后自动继续 | 开 | 你手动暂停后 6 秒内不会抢回控制权 |
| 播完自动翻页 | 开 | 连续 3 次翻页无变化会自动停，防止空转 |
| 自动填本页答案 | 开 | 只在非考试页生效 |
| 自动提交 | **关** | 打开后一旦提交无法撤回，建议先手动核对几次 |
| 处理离开确认弹窗 | 开 | 只会点「留在本页 / 取消」，**不会替你跳过未完成内容** |
| 播放倍速 | **1.0x** | 优学院有学习时长校验，加速容易被判定异常 |

## 三、题库

### 格式

JSON 数组，字段兼容常见优学院脚本（`question/q/title`、`answer/a/correctAnswer` 都能识别）：

```json
[
  {
    "question": "中国共产党人的初心和使命是（ ）",
    "type": "single",
    "answer": "B"
  },
  {
    "question": "实践是检验真理的唯一标准。",
    "type": "judgement",
    "answer": "正确"
  },
  {
    "question": "新民主主义革命的三大法宝是（ ）",
    "type": "multiple",
    "answer": "ABC"
  }
]
```

- `type`：`single` / `multiple` / `judgement` / `completion`，可省略（省略时脚本按页面题型推断）。
- 单选多选填字母；判断题填 `正确`/`错误`（也接受 `对/错`、`A/B`）；填空题填文本。
- 匹配顺序：完全一致 → 互相包含 → 相似度 ≥ 0.84（按二字组 Dice 系数）。所以题干里的题号、标点、空格差异不影响匹配。

### 导入 / 导出

- 面板「📥 导入题库」选 JSON 文件，会**合并去重**（按归一化题干）；
- 「📤 导出题库」把当前题库下载成 JSON，方便备份或分享；
- 题库存在油猴存储 `ulch_bank`，同时兼容读取 `ul_qbank` / `qbank`（其它同类脚本的键），首次加载会自动迁移。

### 没有题库怎么办

脚本不会凭空生成答案。三种办法：

1. 用其它优学院脚本导出的题库（格式基本兼容，导入时会自动认字段）；
2. 自建：手动做一遍，把题干和正确答案按上面格式录进去；
3. 只用播放/翻页功能，题目留给自己做——把「自动填本页答案」关掉即可。

## 四、适配情况

| 场景 | 状态 | 依据 |
|---|---|---|
| 视频自动播放 / 静音 | ✅ 已适配 | `video` 元素 + `.mejs__overlay-play` 覆盖层兜底 |
| 播完自动翻页 | ✅ 已适配 | `.next-page-btn` 及「下一页/下一节/下一章」文案兜底 |
| 单选 / 多选 / 判断 / 填空 | ✅ 已适配 | `.question-item`、`.question-title`、`.ul-radio__label`、`.ul-checkbox__label`、判断题 `icon-zhengque` / `icon-cuowu1` |
| 作业页（`homework.do`） | ✅ 可作答，不自动提交 | 与课件练习题同一套识别逻辑 |
| 考试页（`utest` / `exam`） | ⚠️ 仅手动填充 | 自动作答与自动提交默认关闭，手动填充前会二次确认 |
| 页面在 iframe 内 | ✅ 基本可用 | 脚本注入所有 frame；视频进度和「播完」事件通过 postMessage 回传主页面翻页 |
| 课件 PPT 逐页翻页 | ❌ 未适配 | 没有可靠的"已看完"判定，强翻容易漏页 |

### 为什么有些地方没法完全适配

1. **优学院有多套前端**：`learnCourse.html`（老）、`learnCourseNew`、`umooc.com.cn`、`utest` 考试系统，DOM 结构并不统一，选择器只能取多个真实在跑脚本的交集。若你的学校用的是定制域名/定制版，可能要补一个选择器。
2. **考试场景我主动不做自动化**：误提交、错答的代价不可逆，且多数学校把考试监控单列。这是设计取舍，不是能力缺失。
3. **PPT 课件分页**：优学院的课件"已看完"状态没有统一的 DOM 标记，只能靠计时猜测，猜错会漏内容，所以不做。
4. **倍速**：脚本支持到 2.0x，但默认 1.0x。优学院会记录学习时长，异常倍速可能导致进度回退——这是平台侧风控，脚本无法规避，也不应规避。

### 替代方案

- 需要 PPT 自动翻页：用「下一步/下一节」按钮手动推进，或只在视频页开自动翻页。
- 需要考试自动作答：不建议。至少把「自动填本页答案」关掉，用面板的「📝 填充本页」在确认后再执行。
- 学校用定制域名（如 `xxx.edu.cn` 代理优学院）：在脚本头部 `@match` 里加一行 `*://*.你的域名/*`，重新保存即可。

## 五、脚本没反应？用「诊断」

点面板 **🔍 诊断**，会把当前页面的结构信息（视频数量、题目容器命中数、选项容器命中数、下一页按钮、题库条数、首题文本）复制到剪贴板，同时打印到 F12 控制台。

把这段 JSON 发出来，就能定位是"选择器不匹配"还是"题库没命中"——不用猜。

## 六、边界与风险

- 脚本**不联网**（没有 `@connect`、没有 fetch/XHR），题库只存本地，不会外传。
- 脚本**不模拟鼠标键盘**、不伪造学习时长，只做"播放 / 点击下一页 / 勾选答案"三件事。
- 自动刷课违反多数平台的用户协议，学校通常认定为学术不端。是否使用、用到什么程度，请自行判断并承担后果。
- 已知局限：题库答案正确性由题库决定；相似度匹配存在小概率误配（面板会显示"未匹配 N"，建议抽查）。
