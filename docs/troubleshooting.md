# 排查手册

> 先做一件事：点面板 **🔍 诊断**，把复制到的 JSON 贴到 issue 里。80% 的问题看这段 JSON 就能定位。

---

## 1. 面板不出现

| 检查 | 做法 |
|---|---|
| 是否在脚本生效页面 | 地址需含 `learnCourse` / `learnCourseNew` / `homework` / `quiz` / `utest` |
| 脚本是否启用 | 管理器图标上的数字，或管理面板里的开关 |
| 是否被其它脚本干扰 | 临时禁用其它优学院相关脚本再刷新 |
| 是否学校定制域名 | 在脚本头 `@match` 加一行 `*://*.你的域名/*` 后重新保存 |

仍不出现：F12 → Console，搜索 `[优学院助手]`，看有没有加载日志和报错。

## 2. 视频不自动播放

1. 浏览器自动播放策略会拦截无用户交互的播放 —— 脚本连续失败 3 次后会提示，**手动点一次视频画面**即可接管；
2. 确认页面上确实存在 `<video>`（诊断 JSON 的 `视频` 字段为空说明播放器在跨域 iframe 里）；
3. 若播放器是 mejs，脚本会兜底点击 `.mejs__overlay-play`；定制皮肤可能没有该类名，需反馈。

## 3. 播完不翻页

- 诊断 JSON 里 `下一页按钮.找到` 为 `false` → 按钮类名不是 `.next-page-btn`，把该类名反馈到 issue；
- 若连续 3 次点击后页面无变化，脚本会**自动停用自动翻页**并在面板提示，这是防死循环保护，不是故障；
- 已到最后一节时不会再有下一页，属正常。

## 4. 题目未匹配

| 现象 | 原因 | 处理 |
|---|---|---|
| 面板显示「未匹配 N」 | 题库里没有这道题，或题干差异过大 | 补齐题库；相似度阈值 0.84 |
| 选项一个都没勾 | 选项容器类名不同 | 看诊断 JSON 的 `选项容器` 命中数，为 0 则反馈 |
| 判断题点错 | 页面用文字而非图标 | 题库答案改填 `正确` / `错误` 文本 |
| 多选题只勾了一个 | 答案格式不是连续字母 | 用 `ABC` 或 `A,B,C` |

## 5. 题库导入失败

- 必须是 **JSON 数组**，不是对象、不是带注释的 JSON；
- 编码用 UTF-8（记事本另存为时注意）；
- 字段至少包含题干和答案，题干预留 8 个字以上，否则容易被相似度过滤掉。

## 6. 装了倍速扩展后，面板设的倍速"没生效"

**现象**：面板显示 1.5x，但视频实际速度不对；或视频速度忽快忽慢（1x 与 2x 之间反复切换）。

**原因**：Global Speed 之类的扩展与本脚本改的是同一个 `video.playbackRate`，脚本每 2 秒会把
它拉回面板设定值，扩展又改回去，形成拉锯。

**处理**（三选一，详见 [global-speed.md](global-speed.md)）：

1. 只用脚本倍速，把扩展在 `ulearning.cn` 上停用；
2. 脚本面板与扩展设成**同一个值**（例如都 1.5x）；
3. 点面板「⏸ 暂停」后再用扩展控速 —— 注意此时自动翻页与自动作答也会停止。

## 7. 自动提交没生效

依次确认：`自动提交` 已勾选 → 当前不是考试页 → 本页**没有未匹配题** → 页面上存在文案为「提交 / 提交答案 / 保存并提交 / 交卷」的按钮。
任一条件不满足都不会提交，这是刻意的保护设计。
